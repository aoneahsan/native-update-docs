# White-label questions

## Do I get the source code with a license?

No. A license means we run Native Update for you, under your name. The code changes hands only with a
[buyout](https://nativeupdate.aoneahsan.com/white-label/buyout).

## What does the buyout hand over?

The source of every repository that builds Native Update: the plugin (`src/`, `android/`, `ios/`), the CLI (`cli/`),
the server (`backend/`), the website and dashboard (`website/`) and the docs site. After a buyout we stop selling
Native Update to anyone else; licenses sold before keep their terms.

## Can it run on our own servers?

With a license, we host it. To run it yourself you need the code, which comes with the buyout.

## Can you sell the same thing to someone else?

Yes, until someone buys the source outright.

## What do my customers install?

The `native-update` plugin from npm, pointed at your server. See [what is delivered](./delivery#plugin-and-cli).

## Is there an Android or iOS app to license?

Not today. The dashboard's Android app is not on Google Play yet, so it isn't offered. Your customers' own Capacitor
apps use the plugin as usual.

## How do I pay?

By card through Polar, the merchant of record, on a checkout page for the exact total from the
[pricing page](https://nativeupdate.aoneahsan.com/white-label/pricing).

## Can you change it for us?

Yes, as [custom work](https://nativeupdate.aoneahsan.com/white-label/custom-work), quoted separately.
