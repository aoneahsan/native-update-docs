# White-label and licensing

Native Update can run under another company's name. Your customers sign in to a dashboard with your logo on it, on
your domain, and their Capacitor apps check your update server for releases. The Native Update team hosts it,
deploys it and keeps it current.

There are two ways to get it:

| | White-label license | Source buyout |
|---|---|---|
| Who runs it | We do, under your name | You do, from the code |
| Source code | Not included | Every repository that builds Native Update |
| Others can buy it | Yes, until a buyout | No: we stop selling it |
| Updates | Included months, then renewals | Included months, then renewals |
| Changes only you need | Custom work, quoted separately | Custom work, quoted separately |

Prices, the bundle discount and the renewal plans are on the
[white-label pricing page](https://nativeupdate.aoneahsan.com/white-label/pricing). That page reads them from our
licensing service, so it is the one place they are current; these docs don't repeat them.
