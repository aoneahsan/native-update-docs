# From Capawesome's update and review plugins

<CheckedLine slug="capawesome-app-update-review" />

`@capawesome/capacitor-app-update` and `@capawesome/capacitor-app-review` are two small MIT plugins that do one job each, for free. If that's all you need, keep them. Moving only makes sense when you also want live updates and would rather run all three from one package.

## 1. Add the plugin

```bash
yarn add native-update
npx cap sync
```

It needs what any Capacitor 8 plugin needs ([requirements](/getting-started/installation)). Then [initialize it once at boot](/getting-started/quick-start).

## 2. Replace the Play update flow

Native Update's flow lives in the [App Update API](/reference/sdk/app-update/methods): `getAppUpdateInfo()`, `performImmediateUpdate()`, `startFlexibleUpdate()`, `completeFlexibleUpdate()` and `openAppStore()`.

```ts
const info = await NativeUpdate.getAppUpdateInfo();
```

iOS has no in-app update flow, so [the overview](/reference/sdk/app-update/overview) explains what happens there.

## 3. Replace the review prompt

Use [`canRequestReview()` and `requestReview()`](/reference/sdk/app-review/methods). The store decides whether the dialog appears, on every library, and [the limits are written down here](/reference/sdk/app-review/overview).

## 4. Remove the two plugins

```bash
yarn remove @capawesome/capacitor-app-update @capawesome/capacitor-app-review
npx cap sync
```

This changes native code, so it ships in a store build.
