# Hot Updater and Native Update

<CheckedLine slug="hot-updater" />

Hot Updater runs the update backend on your own cloud account, on Supabase, Cloudflare, AWS, Firebase, Vercel or Azure, with no vendor in the path. Its users pay their own cloud bills and run it themselves.

## Nothing to migrate

Hot Updater apps are React Native or Expo, and we can't serve either yet. Native Update is a Capacitor plugin today.

If owning the backend is the reason you chose Hot Updater, the same option exists for a Capacitor app here: [Backend overview](/backend/overview) explains running your own server against our [API contract](/backend/api-contract). It's real work, and that page says how much.
