# Hot Updater and Native Update

<CheckedLine slug="hot-updater" />

Hot Updater runs the update backend on your own cloud account, on Supabase, Cloudflare, AWS, Firebase, Vercel or Azure, with no vendor in the path. Its users pay their own cloud bills and run it themselves.

## Hosted, or your own server

A bare React Native app on Android can use the [React Native SDK](/frameworks/react-native). Expo apps aren't tested with it and its iOS side isn't ready, so those stay on Hot Updater.

If owning the backend is why you chose Hot Updater, that option exists here too: [Backend overview](/backend/overview) explains running your own server against our [API contract](/backend/api-contract). It's real work, and that page says how much.

## The facts, dated

Hot Updater's pages didn't state device-verified signing, automatic rollback, percentage rollouts, channels, delta updates, an in-app store update flow, a review prompt, background checks, a CLI plus HTTP management API, or Capacitor, Flutter or native app support, so those rows are left out.
