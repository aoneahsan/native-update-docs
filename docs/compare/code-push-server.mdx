# Microsoft code-push-server and Native Update

<CheckedLine slug="code-push-server" />

Microsoft retired hosted App Center CodePush on March 31, 2025, and archived this standalone server on May 20, 2025. It still runs, and it's free, but the repository is read-only.

## If your app is React Native

Native Update serves Capacitor only today. React Native, Flutter and native packages are not available yet, so we can't take this app. [The list](/compare) has services that say they serve React Native.

## If your app is Capacitor or Cordova

This one is a real move, and it has its own guide: [Migrate from CodePush](/how-to/migrate-from-codepush) maps each CodePush call and walks through running both side by side.
