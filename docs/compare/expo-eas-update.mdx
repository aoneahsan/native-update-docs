# EAS Update and Native Update

<CheckedLine slug="expo-eas-update" />

EAS Update ships updates to React Native apps built with `expo-updates`, and its branches, channels and rollbacks are wired into the Expo toolchain you already build with. If your app is on Expo, that's the right tool.

## Expo apps stay on Expo

We have nothing to offer an Expo app. `native-update` is a Capacitor plugin, and our React Native work hasn't shipped.

Teams that run Expo for one product and Capacitor for another can use both side by side. On the Capacitor app, [channels](/how-to/manage-channels) play the part EAS branches do, and a rollout percentage is set on each release.
