# CodePushGo and Native Update

<CheckedLine slug="codepushgo" />

CodePushGo sells hosted live updates for React Native, with development, beta and production channels and encrypted delivery, at $12 a month billed yearly. If that's your stack, compare it with the other React Native services in [the list](/compare), not with us.

## Signed, not encrypted

A React Native app on Android can move: the [React Native SDK](/frameworks/react-native) loads a signed bundle from Native Update and keeps the one built into the APK as the fallback. On iOS it isn't ready yet, so an app that needs iOS updates stays on CodePushGo.

The difference worth knowing before you move: CodePushGo encrypts bundles so only your app can read them. We sign them, and the device refuses a bundle whose signature or checksum doesn't match; [signing and integrity](/concepts/bundle-integrity-and-signing) covers what that does and doesn't protect. Development, staging and production channels exist here too.

## The facts, dated

CodePushGo's pages didn't state automatic rollback, delta updates, self-hosting, an in-app store update flow, a review prompt, background checks, a CLI plus HTTP management API, Capacitor, Flutter or native app support, or a free plan, so those rows are left out.
