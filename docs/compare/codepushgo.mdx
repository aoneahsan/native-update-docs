# CodePushGo and Native Update

<CheckedLine slug="codepushgo" />

CodePushGo sells hosted live updates for React Native, with development, beta and production channels and encrypted delivery, at $12 a month billed yearly. If that's your stack, compare it with the other React Native services in [the list](/compare), not with us.

## No React Native package yet

We'd have to turn you away today. Our only package is the Capacitor plugin; the React Native one is planned and not published.

One difference is worth knowing for a future Capacitor app. CodePushGo encrypts bundles so only your app can read them. We sign them, and the device refuses a bundle whose signature or checksum doesn't match; [signing and integrity](/concepts/bundle-integrity-and-signing) covers what that does and doesn't protect.

## The facts, dated

CodePushGo's pages didn't state automatic rollback, delta updates, self-hosting, an in-app store update flow, a review prompt, background checks, a CLI plus HTTP management API, Capacitor, Flutter or native app support, or a free plan, so those rows are left out.
