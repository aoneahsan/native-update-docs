# Moving from Ionic Appflow

<CheckedLine slug="ionic-appflow" />

Ionic stopped selling Appflow to new customers in February 2025 and says existing customers keep access <RivalLink href="https://ionic.io/blog/important-announcement-the-future-of-ionics-commercial-products">through December 31, 2027</RivalLink>. You have time. Move on a normal release, not in a rush.

Native Update replaces Appflow's live updates. It doesn't replace its cloud builds, so keep building your native app in your own CI or on your own machine.

If your Appflow app is React Native, stop here: our only package is the Capacitor plugin, and there's no React Native version yet.

## 1. Install, and make a signing key

```bash
yarn add native-update
npx cap sync
npx native-update keys generate --type rsa --size 4096
```

Capacitor 8 is required; [the installation page](/getting-started/installation) lists the rest. Register the app on [the dashboard](https://nativeupdate.aoneahsan.com/login) once the plugin is in.

## 2. Remove Appflow's live update code

Replace the Appflow live update code in your boot path with the [Quick Start](/getting-started/quick-start) setup. Bundles here must be signed, and [the device checks the signature](/concepts/bundle-integrity-and-signing) before a bundle can run.

```ts
await NativeUpdate.notifyAppReady();
const result = await NativeUpdate.sync();
```

## 3. Map your environments

Test, QA and production become [channels](/how-to/manage-channels). A percentage rollout is set on each release.

## 4. Move the release step in CI

```bash
npx native-update deploy ./dist --app com.example.app --rollout 5 --wait
```

[The CI guide](/how-to/ci-cd-github-actions) has a full pipeline. Remove the old plugin in one store build, and keep Appflow live until that build has spread.
