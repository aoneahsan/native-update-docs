# AppsOnAir and Native Update

<CheckedLine slug="appsonair" />

AppsOnAir is one toolkit for native, Flutter and React Native apps. Alongside CodePush-style releases it distributes test builds, forces a critical update and sends push. That spread of stacks is exactly what we don't have.

## If you're on AppsOnAir today

Whatever stack your app uses there, we can't take it. Native Update ships a Capacitor plugin and nothing else for now; the React Native, Flutter and native packages aren't out.

If you also maintain a Capacitor app, the forced-update part has a counterpart in our plugin: the [App Update API](/reference/sdk/app-update/overview) runs the Play in-app update flow. For live updates on that app, [your first update](/tutorials/first-ota-update) is a single walk-through from install to a signed bundle on a device.
