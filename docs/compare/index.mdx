# Moving to Native Update

Native Update has an SDK for Capacitor, React Native, Flutter and native Android. Capacitor apps update on Android and iOS; the other three run on Android today, and their iOS side isn't ready. So whether you can move depends on your stack and on whether you need iOS updates now, and each page below says which.

Each page carries prices and feature rows read on that service's own pages, with the date. A row reading "Not stated on the pages we checked" isn't a no. For the side-by-side view, see [the comparison on our site](https://nativeupdate.aoneahsan.com/compare).

## From a Capacitor service

These are real moves, step by step.

- [Capgo](/compare/capgo)
- [Capawesome Cloud Live Updates](/compare/capawesome-cloud)
- [Ionic Appflow](/compare/ionic-appflow), where access ends on December 31, 2027
- [Capawesome's App Update and App Review plugins](/compare/capawesome-app-update-review)
- [Microsoft code-push-server](/compare/code-push-server), if your app is Capacitor or Cordova

## From a React Native or Flutter service

On Android these are moves too, through the [React Native SDK](/frameworks/react-native) or the [Flutter SDK](/frameworks/flutter). An app that needs iOS updates today, or an Expo app, is better off where it is, and these pages say so.

- [Expo EAS Update](/compare/expo-eas-update)
- [Shorebird](/compare/shorebird), for Flutter
- [Revopush](/compare/revopush)
- [CodePushGo](/compare/codepushgo)
- [Cresc](/compare/cresc)
- [Stallion](/compare/stallion)
- [Codemagic Patch](/compare/codemagic-patch)
- [Appcircle CodePush](/compare/appcircle-codepush)
- [AppsOnAir](/compare/appsonair)
- [Hot Updater](/compare/hot-updater)
