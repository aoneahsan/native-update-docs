# Moving to Native Update

Native Update serves Capacitor only today. React Native, Flutter and native packages are not available yet. So whether you can move depends on your stack, and most of the pages below say so plainly.

Each page carries prices and feature rows read on that service's own pages, with the date. A row reading "Not stated on the pages we checked" isn't a no. For the side-by-side view, see [the comparison on our site](https://nativeupdate.aoneahsan.com/compare).

## From a Capacitor service

These are real moves, step by step.

- [Capgo](/compare/capgo)
- [Capawesome Cloud Live Updates](/compare/capawesome-cloud)
- [Ionic Appflow](/compare/ionic-appflow), where access ends on December 31, 2027
- [Capawesome's App Update and App Review plugins](/compare/capawesome-app-update-review)
- [Microsoft code-push-server](/compare/code-push-server), if your app is Capacitor or Cordova
