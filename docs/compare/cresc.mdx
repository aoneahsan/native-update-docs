# Cresc and Native Update

<CheckedLine slug="cresc" />

Cresc charges a flat monthly price metered by daily update checks rather than monthly active users, which is a different way of paying from ours. It serves React Native, with CDN bandwidth included on every tier.

## Stay on Cresc for this app

A React Native app can't use Native Update yet. We publish one package, for Capacitor, and React Native support isn't released.

If you're weighing the two payment models for a Capacitor project, our limits are counted per plan on [Plans and limits](/backend/plans-and-limits). Read that page before comparing with queries per day, because the two don't convert neatly.

## The facts, dated

Cresc's pages didn't state device-verified signing, automatic or manual rollback, percentage rollouts, channels, delta updates, self-hosting, an in-app store update flow, a review prompt, background checks, a CLI plus HTTP management API, or Capacitor, Flutter or native app support, so those rows are left out.
