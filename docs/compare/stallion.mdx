# Stallion and Native Update

<CheckedLine slug="stallion" />

Stallion offers hosted React Native updates with 10,000 MAU on its free plan, rollback logs, and an on-premise option if you outgrow the hosted one.

## A React Native app, so no

We can't run Stallion's job for a React Native app; our React Native package isn't released and the plugin we ship is Capacitor-only.

For a Capacitor app, rollback works differently from a log you read afterwards. A bundle that never confirms it started goes back to the last good one by itself; [Roll back a bundle](/how-to/roll-back-bundle) has the details and the manual route.
