# Stallion and Native Update

<CheckedLine slug="stallion" />

Stallion offers hosted React Native updates with 10,000 MAU on its free plan, rollback logs, and an on-premise option if you outgrow the hosted one.

## What this means for you

Native Update serves Capacitor only today. React Native, Flutter and native packages are not available yet, so there's no migration to walk through and we won't pretend otherwise.

Your current app stays where it is. This page is useful in one case: your next app, or a rewrite, is Capacitor. Then start with [Installation](/getting-started/installation), ship [your first update](/tutorials/first-ota-update), and read [how signing works](/concepts/bundle-integrity-and-signing).
