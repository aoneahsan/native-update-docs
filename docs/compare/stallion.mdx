# Stallion and Native Update

<CheckedLine slug="stallion" />

Stallion offers hosted React Native updates with 10,000 MAU on its free plan, rollback logs, and an on-premise option if you outgrow the hosted one.

## Rollback, by itself

A React Native app on Android can come across: the [React Native SDK](/frameworks/react-native) loads a signed bundle and the Play update and review flows sit in the same package. On iOS it isn't ready, so an app that needs iOS updates today stays on Stallion.

Rollback works differently from a log you read afterwards. A bundle that never calls `notifyAppReady()` goes back to the last good one after two starts, on its own; [Roll back a bundle](/how-to/roll-back-bundle) has the details and the manual route.

## The facts, dated

Stallion's pages didn't state device-verified signing, automatic rollback, channels, delta updates, an in-app store update flow, a review prompt, background checks, a CLI plus HTTP management API, or Capacitor, Flutter or native app support, so those rows are left out.
