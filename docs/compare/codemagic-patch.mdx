# Codemagic Patch and Native Update

<CheckedLine slug="codemagic-patch" />

Codemagic Patch is OTA for React Native, including Expo apps, from the team behind the Codemagic build service. It comes hosted, with the first 100K MAU free, or as a Docker Compose install you run yourself.

## Where that leaves you

Building on Codemagic with React Native is a setup we can't join. There is no React Native package from us today, only the Capacitor plugin, so stay with Patch.

Nothing about Codemagic stops a Capacitor app from using us later: the plugin doesn't care where the native build happens. Read [Installation](/getting-started/installation) for the Capacitor 8 requirement, and [the CI guide](/how-to/ci-cd-github-actions) for how a release step fits after your build.

## The facts, dated

Codemagic's pages didn't state device-verified signing, automatic rollback, delta updates, an in-app store update flow, a review prompt, background checks, or Capacitor, Flutter or native app support, so those rows are left out.
