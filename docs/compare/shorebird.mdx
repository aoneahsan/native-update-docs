# Shorebird and Native Update

<CheckedLine slug="shorebird" />

Shorebird patches compiled Dart in Flutter apps, and its free Hobby plan covers 5,000 patch installs a month. A web-bundle updater like ours can't do that, because a Capacitor bundle is HTML, CSS and JavaScript and a Flutter release isn't.

## Flutter apps belong on Shorebird

Our Flutter package doesn't exist yet, so there's no path from Shorebird to us. Keep patching with it.

If you're choosing a stack for a new app and live updates matter, [how OTA updates work](/concepts/how-ota-updates-work) shows exactly which layer a Capacitor update can replace and which still needs a store build.
