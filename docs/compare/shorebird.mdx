# Shorebird and Native Update

<CheckedLine slug="shorebird" />

Shorebird patches compiled Dart in Flutter apps, and its free Hobby plan covers 5,000 patch installs a month. A web-bundle updater like ours can't do that, because a Capacitor bundle is HTML, CSS and JavaScript and a Flutter release isn't.

## Two different Flutter jobs

Shorebird patches the Dart code of apps installed from the App Store and Google Play. We don't load downloaded code in an app that came from Google Play, and our Flutter package doesn't update iOS apps yet, so for those installs Shorebird is the tool.

The [Flutter SDK](/frameworks/flutter) does two other things. It replaces the files a Flutter app reads (images, config, copy) on every Android install, signed and checked on each cold start. And for an app you hand out yourself (a direct APK, an enterprise rollout, a test group) it can replace the Dart code too: [`bundle flutter-patch`](/reference/cli/bundle-flutter-patch) turns a release APK into a patch that only runs on the exact Flutter engine it was built for.
