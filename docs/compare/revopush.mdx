# Revopush and Native Update

<CheckedLine slug="revopush" />

Revopush is a CodePush-compatible service, so a React Native app coming off Microsoft's retired App Center can keep the same SDK calls, Expo projects included. That's a job we can't do for you.

## Coming off App Center

For a React Native app, Revopush or another service in [the list](/compare) is the move. We only have a Capacitor plugin right now.

If the app you took off App Center was Capacitor or Cordova, that's different: [Migrate from CodePush](/how-to/migrate-from-codepush) maps each CodePush call to ours and runs both plugins side by side until the old one can go.

## The facts, dated

Revopush's pages didn't state automatic rollback, channels, delta updates, an in-app store update flow, a review prompt, background checks, a CLI plus HTTP management API, or Capacitor, Flutter or native app support, so those rows are left out.
