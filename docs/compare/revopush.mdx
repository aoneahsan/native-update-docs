# Revopush and Native Update

<CheckedLine slug="revopush" />

Revopush is a CodePush-compatible service, so a React Native app coming off Microsoft's retired App Center can keep the same SDK calls, Expo projects included. Keeping those calls is something we can't do: our SDK has its own API.

## Coming off App Center

For a React Native app on Android that can change a few calls, the [React Native SDK](/frameworks/react-native) is the move: a signed bundle loaded at start, rollback after two unconfirmed starts, and the Play update and review flows. If the app must keep its CodePush calls, or needs iOS updates today, Revopush is the one.

If the app you took off App Center was Capacitor or Cordova, that's different: [Migrate from CodePush](/how-to/migrate-from-codepush) maps each CodePush call to ours and runs both plugins side by side until the old one can go.

## The facts, dated

Revopush's pages didn't state automatic rollback, channels, delta updates, an in-app store update flow, a review prompt, background checks, a CLI plus HTTP management API, or Capacitor, Flutter or native app support, so those rows are left out.
