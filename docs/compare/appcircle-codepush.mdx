# Appcircle CodePush and Native Update

<CheckedLine slug="appcircle-codepush" />

Appcircle puts React Native OTA updates inside the same platform that builds and distributes the app, and it runs on Kubernetes or OpenShift if your company wants it in-house. Rollout percentages and rollbacks sit next to the build pipeline. We don't build apps at all, and we don't serve React Native.

## Why there's no move here

A React Native app has nowhere to land with us yet. Our plugin is for Capacitor, and React Native, Flutter and native packages are planned, not shipped. Keep Appcircle for the app you have.

The one case where this page matters: a separate product your company writes in Capacitor. That team can start at [Installation](/getting-started/installation) without touching the Appcircle pipeline, and [how OTA updates work](/concepts/how-ota-updates-work) explains what a web bundle can and can't change.
