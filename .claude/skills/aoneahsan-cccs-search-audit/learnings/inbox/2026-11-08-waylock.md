# Learning inbox — waylock, 2026-11-08

1. **Probe that lied (proposed P11 extension):** Docusaurus with `trailingSlash: false` on GitHub Pages answers the slash variant (`/guide/x/`) with 404, while the clean URL is 200. Detect: `curl -s -o /dev/null -w '%{http_code}' https://<docs>/guide/<page>/`. Fix that worked: write `<route>/index.html` per page with `noindex`, a canonical and a 0-second refresh to the clean URL, from the build plugin after the page list is final.
2. **Docusaurus trap:** a second `exclude:` key in the docs preset options silently overrides the first in JS, and `tsc` catches it only as TS1117 when `docusaurus.config.ts` is typechecked. A file meant to stay out of the guide (`docs/PACKAGES.md`) was published until the two lists were merged.
3. **Stack-specific fix:** a comparison hub on a prerendered TanStack site: one typed `/compare/$slug` route for the router, one static file per rival; the static-vs-typed route coverage check must map `compare/<slug>.html` to the param route and strip TanStack's trailing slash on index routes.
