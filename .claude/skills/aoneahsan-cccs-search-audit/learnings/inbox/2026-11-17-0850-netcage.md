Target: `aoneahsan-cccs-search-audit` catalogue SA-P05/SA-P06 and the Docusaurus skill. ## Generated page exclusion

Target: Docusaurus site-index guidance. The site-index plugin must use the docs plugin's exclude list. Before NetCage `15f283e`, `/sitemap` linked an excluded `docs/PACKAGES.md` and the build failed after a dependency pass; after the shared exclusion, the docs build passed and the live sitemap showed 38 routes. Evidence: `netcage-docs/plugins/site-index/index.js`, run `F-DOC-101`.

## Probe output is only what it measured

Target: search-audit probe guidance. A Windows `subprocess.run(..., text=True)` crawl decoded UTF-8 HTML as cp1252; 12 website and three docs pages falsely appeared as probe errors. Decode captured bytes as UTF-8 and parse `link`/`meta` attributes with an HTML parser. The corrected 2026-11-17 live sweep found 31/31 website and 38/38 docs sitemap URLs returning 200 with one self canonical and no robots noindex. The response body is not a robots directive.
