# Lessons from the system-build session (2026-10-27)

All three are already applied in place. They are recorded here for history.

1. **Wrong advice in our own skill.** `aoneahsan-cccs-docusaurus/references/search-analytics-ai.md` told docs
   sites to keep a canonical in `headTags`. That is the root cause of SA-P01 on Empora (`docusaurus.config.ts:32`)
   and on the other docs sites with a doubled canonical. Corrected the same day.
2. **Probe lied.** `robots-effective` on the bare prefix `/admin` reported "allowed" for a file with
   `Disallow: /admin/` (labflow robots, 2026-10-27). Probes now test a child path. → `probes.md`.
3. **New pattern SA-P19.** ZTools tool URLs answered 403 to the GSC agent and 200 a day later: a CDN
   challenge on bursts. → `issue-catalogue.md`.
