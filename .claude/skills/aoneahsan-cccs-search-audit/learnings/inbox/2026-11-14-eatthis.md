# Learning — eatthis, 2026-11-14

- **A hand-written sitemap generator hides stale lastmod.** Eat This builds `public/sitemap.xml` from an inline
  `build:feeds` script with dates typed into a map; editing `public/sitemap.xml` directly is silently overwritten by the
  next build. Probe: after any copy change, `grep -c <today> sitemap.xml` on the live host, and look for date literals in
  the generator (`git grep -n "const W='20"` in package.json scripts). Fix in the generator, never in the output.
- **pricing.md is easy to miss when llms.txt exists.** Probe both: `curl -sI /<host>/pricing.md` must be 200 with
  `text/markdown` (Cloudflare Pages needs a `_headers` entry for `.md`), and llms.txt should link it.
- **Payment-path wording is an AEO consistency check.** When a fleet rule changes how something is paid (2026-11-14:
  white-label never through Polar), grep llms.txt, pricing.md, Terms, Privacy and docs for the old provider name.
