# Learning inbox — rentparty, search audit 2026-11-10-0018

1. **Stale calibration table.** Three 2026-10-27 known-bads are fixed upstream (strata-storage `llms.txt` now
   `text/plain`, labflow sitemap has no `/login`, smsapp unknown path is 404). Calibrate extractor probes on planted
   strings and status probes on their own output; drop the fixed rows from the table.
2. **Lying probe (SA-P03 `assets`).** `og:image|twitter:image` also matches `og:image:width`, `:height`, `:type` and
   `:alt`, so `1200`, `630`, `image/png` and the alt's first word are fetched as relative URLs and reported 404.
   Match `property=["']?(og:image|twitter:image)["']?\s` (seen on zaions-portfolio the same day: a fleet fix).
3. **Lying probe (JSON-LD on Docusaurus).** The built HTML writes `<script data-rh=true type=application/ld+json>`;
   `grep '<script type="application/ld+json">'` returns nothing. Match `<script[^>]*ld\+json[^>]*>`.
4. **SA-P06 sweep gap on Docusaurus.** Checking `/search` alone passes a site whose tag, archive and author pages are
   indexable. Read the probe set from `sitemap.ignorePatterns`: `/tags`, `/tags/<first>`, `/blog/tags`,
   `/blog/tags/<first>`, `/blog/archive`, `/blog/authors`. Stack fix (proven in rentparty-docs `608a3d5`): one
   `NoIndex` head component plus thin `@theme-original` wrappers for DocTagsListPage, DocTagDocListPage,
   BlogTagsListPage, BlogTagsPostsPage, BlogArchivePage, Blog/Pages/BlogAuthorsListPage and
   Blog/Pages/BlogAuthorsPostsPage. Never `Disallow` them. Belongs in `aoneahsan-cccs-docusaurus` too.
5. **AI-05 offers drift (stack fix).** A home page `SoftwareApplication` that lists Free alone while `/pricing` sells
   paid plans fails AI-05. Build `offers` from the plan registry the pricing page reads (rentparty
   `src/public/site-pages/app-offers.ts`): a monthly `UnitPriceSpecification`, and for a per-seat plan
   `referenceQuantity` 1 seat plus `eligibleQuantity` min–max. Hold it equal to the dummy with a parity test that is
   shown to fail on a planted price.
6. **Standards disagree on `www`.** The product-audit discoverability check D03 treats a `www` host answering 200 as a
   defect; `cloudflare-hosting.md` names it the correct result for a Pages subdomain. One should cite the other.
7. **Old "NA (accepted)" records are void.** SA-RENTPARTY-003 carried one from 2026-10-28; the 2026-10-30
   no-exceptions rule makes it an open FAIL. Fleet mode should re-open every `NA (accepted…)` record.
8. **Verification trap: a stale service worker on localhost.** A reused automation profile kept a service worker from
   an older `vite preview` on the project's port, so `localhost:<port>` served an old production bundle over the dev
   server (seen as missing UI and minified component names). Before any local render, unregister workers and clear
   caches for that origin, then confirm the page loads `/src/main.tsx` (dev) or the expected `index-<hash>.js`.
