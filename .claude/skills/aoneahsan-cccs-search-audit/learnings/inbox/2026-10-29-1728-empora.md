## 1. Probe that lied: `robots-effective` on groups that open with `Allow: /` → target `references/probes.md`
- **Evidence:** `https://empora.aoneahsan.com/robots.txt` (21 groups, each `Allow: /` then `Disallow: /dashboard` …). Python
  `urllib.robotparser` printed `Y/dashboard/x` for every bot, including `*`.
- **Cause:** robotparser is first-match in file order; `Allow: /` matches first. Google uses longest-match, so the file is
  correct. The probe's existing warning ("first-match approximation") does not say it inverts EVERY result for this shape.
- **Correction:** before trusting robotparser, drop `Allow: /` lines when a group also has Disallows
  (`grep -v '^Allow: /$' robots.txt > robots.eff.txt`), or compute longest-match by hand. Calibrate on this URL: the raw
  parser must print `Y/dashboard/x` (the lie) and the corrected one `n/dashboard/x`.

## 2. Probe that lied: `assets` regex matches `og:image:width` / `og:image:height` → target `references/probes.md`
- **Evidence:** docs home printed `RELATIVE 1200` and `RELATIVE 630` (404) from `<meta property="og:image:width" content="1200">`.
- **Correction:** match `(og:image|twitter:image)["']` (closing quote) so the `:width/:height/:alt` properties are excluded.

## 3. New pattern proposal SA-P20 — page HTML cached for an hour on Firebase Hosting (P2) → target `references/issue-catalogue.md`
- **Seen:** empora 2026-10-29: `firebase.json` set `no-cache` only on `/index.html`; every route and prerendered page got the
  default `cache-control: max-age=3600`, so after a deploy a returning visitor kept the old HTML for an hour, pointing at
  hashed chunks the new release no longer serves (the agent's own browser loaded the previous bundle after a deploy).
- **Detect:** `curl -sI https://<host>/<a-route> | grep -i cache-control` on a route and a prerendered page; FAIL when it is
  not `no-cache` (or `max-age=0, must-revalidate`).
- **Fix (Firebase):** the first `headers` block (`source: "**"`) gets `Cache-Control: no-cache`; `/assets/**` keeps
  `public, max-age=31536000, immutable` in a later block (later blocks win; verified live: route `no-cache`, asset
  `immutable`). Contract test over `firebase.json` (empora `hosting-rewrites.test.ts`).
- **Accept:** routes `no-cache`, hashed assets `immutable`, live.
