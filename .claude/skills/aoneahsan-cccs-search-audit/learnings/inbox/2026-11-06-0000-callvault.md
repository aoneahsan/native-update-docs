# Search audit lessons: callvault, 2026-11-06-0000


1. **Calibration table is stale:** `stratastorage…/llms.txt` (now `text/plain`), `smsapp…/zz-<uuid>` (now 404) and `labflow…/sitemap.xml` (no `/login`) are fixed; keep only planted defects (two-canonical string, absent image, `property=robots`) and `tools.zaions.com/sitemaps.xml`.
2. **Probe lie:** `grep -o '<lastmod>' | wc -l` counts the word inside an XML comment (CallVault `web/sitemap.xml:5`); strip `<!-- … -->` first, or count `<url>`.
3. **Pattern gap:** Docusaurus blog/doc utility pages (`/tags`, `/updates/archive`, `/updates/authors`, `/updates/tags`) are excluded by `ignorePatterns` yet remain indexable with no noindex at all — the catalogue only names `/search`. Candidate SA-P20: "sitemap-excluded generated page without noindex".
4. **Pattern gap:** a release feed whose newest item is several versions behind the shipped `version.json` (drift, not malformed) — P05 passes today; add a freshness clause ("newest item version ≥ shipped version, or a documented reason").
5. **Pattern gap:** an alias host from a previous hosting provider serving an older build publicly — P15 covers "old domain", but the stack-specific fix (Firebase `redirects`/`headers`) is not in the catalogue.
6. `-react-aeo`/`llms.txt` check should include a cross-read of the privacy policy's analytics sentence (AI-05 caught it only because the policy was read for the bot-policy conflict question).

7. Cloudflare Pages `_headers` accepts an absolute `https://<project>.pages.dev/*` block for noindex on the default host. A rewrite-all Firebase redirect `/:path*` does not catch `/`; add `/` separately.
