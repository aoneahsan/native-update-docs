# Learning inbox — trizlink, run 2026-10-30-2253

1. **A home-served SPA family is a canonical defect, not only a soft 404.** Cloudflare Pages `_redirects` sent `/u/*`,
   `/auth/*` … and `/:slug` to `/`, so each answered 200 with the HOME canonical. The `soft404` probe should print the
   body's canonical. Fix shape: a neutral noindex shell per private family, a public shell (no canonical, no noindex) for
   customer content, and the real 404 for absent prerendered families.
2. **Cloudflare Pages `_headers`: one block per path.** A second `/widget/*` block (adding X-Robots-Tag) silently undid the
   first block's `! X-Frame-Options`, refusing customer embeds. Merge per path; probe the detached header after a deploy.
3. **A zone's Browser Cache TTL overrides a Pages `Cache-Control` on the apex** (the pages.dev URL kept `no-cache`). For a
   service worker, register with `updateViaCache: 'none'` instead of relying on the header.
4. **GitHub Pages answers `/feed` and `/sitemap` with the `.xml` files** when no page exists; an extensionless 200 proves
   nothing. Probe the content type.
5. **Docs machine files (llms.txt, JSON-LD offers) drift from the product's prices** — include them in the AI-05 grid.
6. **The `assets` probe read og:image width/height as relative URLs** (two false 404 lines) — a probe bug to fix.
7. Anthropic's documented crawler agents are ClaudeBot, Claude-User and Claude-SearchBot (support.claude.com article 8896518,
