# Learning: eatthis, 2026-11-12

1. **Prerender-only Pages sites 404 their personal routes on a direct load.** A Vite SPA that emits `<route>.html` for
   indexable pages and relies on `404.html` returns HTTP 404 for `/account`, `/admin/*`, `/r/<code>`; the app still
   boots, so a browser check passes while the status is wrong. Probe: `curl -o /dev/null -w %{http_code}` on every
   signed-in route. Fix: emit `noindex` shells (no canonical, out of the sitemap) and Cloudflare `_redirects` rewrites
   (`/admin/* /admin 200`), keeping unknown URLs a real 404.
2. **Docusaurus with `blog: false` ships no feed and no robots.txt.** Add `static/robots.txt` and a config-local plugin:
   `loadContent` reads the docs with `git log -1 --format=%cI` per file, `contentLoaded` adds `/feed`, `postBuild` writes
   `feed.xml`. Link `/feed.xml` with a plain anchor; `<Link>` fails the broken-link check because the file exists only
   after the build.
3. **One global lastmod in a sitemap script lies after a partial change.** Keep a per-URL override map in the generator.
