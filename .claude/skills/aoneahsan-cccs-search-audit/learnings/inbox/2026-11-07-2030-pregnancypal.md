# Pregnancy Pal, /search-audit run 2026-11-07-2030

- **A connection reset can be the machine's network, not the site.** Chromium over TCP got `ERR_CONNECTION_RESET` on `pregnancypal.aoneahsan.com` with Encrypted Client Hello on, while curl, QUIC and `pages.dev` passed. Evidence: `--disable-features=EncryptedClientHello` cleared it on the same host. Before calling a page broken, repeat with that flag and with curl, then report it as a network finding for the owner. Target: `references/` probe calibration.
- **A docs site needs `/feed` as a page, not only `/feed.xml`.** Docusaurus emits only the XML from its blog plugin, so `/feed` was a 404 until a page was added. The same holds for `/sitemap`. Target: SA pattern for sitemap and feed pairs, docs-site row.
- **A probe's own Python can fail open.** A ternary with `if False` in the empties check meant the noindex branch never ran. Keep each condition on its own line in a one-off probe and watch it fail once on a planted page. Target: `references/` evidence contract.
