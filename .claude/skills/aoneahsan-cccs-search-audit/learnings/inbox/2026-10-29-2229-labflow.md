## 1. A probe that lied: `robots-effective` with `urllib.robotparser` (target: `references/probes.md` → robots-effective)

Python's parser applies the FIRST matching rule in a group. A group written `Allow: /` then `Disallow: /dashboard` (the
`ai-bot-policy.md` example shape, and LabFlow's generated file) reads as **allowed** for every path, so the probe printed
`Y/dashboard/x` for all 14 bots on a correct file — the opposite of the truth. Google applies the LONGEST match (ties go to
`Allow`). Evidence: `after/robots-matrix.txt` (longest-match evaluator: 0 mismatches after, 98 before).

Corrected evaluator (calibrated both ways on this run):

```python
def allowed(rules, path):          # rules: [(kind, value)] of the bot's own group, or '*'
    best = ('allow', '')
    for kind, v in rules:
        if v and path.startswith(v) and (len(v) > len(best[1]) or (len(v) == len(best[1]) and kind == 'allow')):
            best = (kind, v)
    return best[0] == 'allow'
```

The probe's own note already warns "Python's parser is a first-match approximation"; the fix is to stop using it.

## 2. A new pattern: canonical names the bare path while the host serves the slash form (proposed SA-P20, P1)

- **Seen:** labflow `SA-LABFLOW-001` (2026-10-29). Prerender wrote `dist/<route>/index.html`; Firebase Hosting serves it at
  `<route>/` and 301s the bare path; the page's canonical, `og:url` and JSON-LD named the bare path while the sitemap
  listed the slash form.
- **Detect:** in `canon-sweep`, FAIL when a page's canonical ≠ its sitemap `<loc>` AND `curl -sI <canonical>` answers 3xx.
- **Fix:** one served-path function feeding canonical, `og:url`, JSON-LD, sitemap, feed and `llms.txt`
  (`labflow/src/lib/seo/served-path.ts`).
- **Accept:** every listed URL's canonical equals its `<loc>` and answers 200 without a redirect.

## 3. Stack recipe for SA-P11 on Firebase Hosting + prerender (target: `issue-catalogue.md` SA-P11 → Fix)

A `/<family>/**` rewrite in front of a fully prerendered family (`/blog/<slug>`, `/compare/<slug>`) only ever answers the
slugs that do NOT exist — static files win first. Drop `/**` for families whose every child is prerendered; give the SPA

separate indexable, addressless shell for a public data-driven family (`/laboratories/<slug>`). Test: parse the route tree
and `firebase.json`; assert absent children of prerendered families are NOT rewritten.

## 6. Fleet-wide (target: `rules-detail/services-integrations.md`, Google-only law)
