# Learning — eatthis, 2026-11-16

- **Docusaurus `sitemap.lastmod: 'date'` reads each page FILE's git date, so data-driven pages go stale.** Eat This's
  docs compare pages are thin `.mdx` files rendering `<Rival slug=…/>` from `src/data/competitors.json`. Refreshing the
  JSON changed every page's visible content and left the sitemap at the old date. `last_update` front matter does not
  help unless `showLastUpdateTime` is on (Docusaurus 3; it was ignored here). Probe: after a data-only change, build and
  `grep -o '<page></loc><lastmod>[^<]*' build/sitemap.xml`. Fix: put a true fact that changed into the page file (here the
  check date in each `description`), commit, then build; or turn `showLastUpdateTime` on and set `last_update`.
- **A Docusaurus build on Node 26 that looks clean may print one ExperimentalWarning** (`localStorage is not available`);
  the ledger's `NODE_OPTIONS=--no-experimental-webstorage` in the build script keeps the log at zero warnings.
