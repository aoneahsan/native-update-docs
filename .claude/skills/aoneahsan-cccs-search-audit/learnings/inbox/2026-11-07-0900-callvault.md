# CallVault, /search-audit run 2026-11-06-0000, second pass

- **Flutter under `--wasm`:** the semantics tree (and so any heading or link probe) stays empty until the placeholder is clicked, the same as CanvasKit, but a probe that reads straight after the first frame can see nothing. Wait for a known label, not a fixed delay. An empty tree with only a handful of nodes can also mean the native entry booted: check `dart.library.html` conditional imports first.
- **A probe straight after a deploy can be interrupted** by the service worker takeover reloading the tab. Count top-level navigations before calling a route broken.
- **IndexNow on a docs host:** the same key file works per host; `200` for two changed docs URLs, sent only after the live page showed the new section.
- **URL check that lied:** a docs route probed under `/docs/...` returned no match while the page was live at `/user-guide/...`. Take the path from the built `sitemap.xml`.
- **Google Play HTML:** the listing page carries several `$x - $y per item` values, because similar apps sit in its data. The app's own value is the one directly after its download count (`"5M+"],null,null,null,null,[2],["$11.99 per item"`). Taking the first match in a page that omits the app's own value reads another app's price. Also, Play pages truncate under WebFetch: read the raw HTML.
- **A price re-check earns its cost:** re-opening five prices at the end found one wrong figure that a first pass had published.
