# Learning inbox — rentparty 2026-10-30-2124

## New pattern candidate: a shipped feature with no docs page and no llms.txt line (AI-05 / AI-07, docs surface)

- **Seen:** City Editions (live since D-211) and the update flow (D-219) had no docs page and no docs `llms.txt` line;
  every canon/robots/sitemap probe still passed, because the probes read what exists, not what is missing.
- **Detection:** list the product decisions (or user-visible merges) dated after the docs repo's last commit; each one
  needs a docs URL in `sitemap.xml` and a line in `llms.txt`. `git -C <docs> log -1 --format=%cs` against the decision log.
- **Fix:** one docs page per feature, words from already-approved product strings when the owner allows (D-220), then
  IndexNow for the new URLs.
- **Accept:** `curl -s <docs>/llms.txt | grep -c '<slug>'` ≥ 1 per feature and the URL answers 200 in the sitemap.

## Probe note: a word-fingerprint ledger counts the printed date

Rent Party's `page-dates.json` fingerprints a page's words including its own "Last updated" date, so moving the date
after a words change produces a second fingerprint; record the final one only (the intermediate never shipped).
