# Learning inbox — habitforge, run 2026-10-29-2105

1. **Probe that lied — `robots-effective` (Python `urllib.robotparser`).** It is first-match, so `Allow: /` before the
   `Disallow` lines reads every private path as allowed. Google and RFC 9309 use longest match. Replace the probe with a
   longest-match evaluation (per group: the longest matching rule wins; ties go to Allow) — HabitForge live, 18 groups,
   0 violations under longest match while robotparser printed `Y` everywhere.
2. **Probe that lied — `assets`.** The `og:image` regex also matches `og:image:width`, `og:image:height` and
   `og:image:alt`, so `1200`, `630` and the alt text were fetched as relative URLs and "failed". Match
   `property=["']og:image["']` exactly.
3. **New pattern candidate — SA-P20 "no lastmod".** Neither host had a `<lastmod>`; house law wants a truthful date on
   every URL. Detect: `grep -o '<lastmod>' | wc -l` equals `<loc>` count. Fix (SPA): per-URL date from the page's own
   date (legal), its newest content entry (feed) or the newest commit to its words (`git log -1 --format=%cs -- <files>`),
   throwing when git history is missing; Docusaurus: `createSitemapItems` from `last_update.date`.
4. **Stack recipe — SA-P11 on Firebase Hosting:** `/section/**` rewrites make every unknown child a 200 shell. One
   rewrite per real route; a hosting-config test asserts unknown children are not served.
