# native-update-docs

Public documentation site for the [`native-update`](https://www.npmjs.com/package/native-update) Capacitor plugin.

- **Live site**: https://nativeupdate-docs.aoneahsan.com (canonical docs for the plugin)
- **Docs source**: this repo
- **Plugin source (private)**: separate repo
- **Marketing site + dashboard**: https://nativeupdate.aoneahsan.com
- **Maintained by**: the Native Update team

Built with [Docusaurus 3](https://docusaurus.io/). Every push to `main` deploys automatically to GitHub Pages via `.github/workflows/deploy-pages.yml` (see `DEPLOY.md`).

---

## Local development

```bash
yarn install
yarn start          # dev server at http://localhost:5960
yarn build          # production build into ./build
yarn serve          # preview the production build at http://localhost:5961
yarn typecheck      # TypeScript-only check, no emit
```

The dev server is configured to bind on port **5960** (registered in `~/.dev-ports.json`).

## Authoring conventions

- **One H1 per page** — Docusaurus uses it for the page title and breadcrumbs.
- **Frontmatter required** on every doc:
  - `title`, `description` (40–160 chars, AI-extractable), `keywords`, `last_update.date`, `last_update.author` (`Native Update team`).
  - Optional: `sidebar_position` for ordering.
- **Team credit** at the bottom of long pages: "Maintained by the Native Update team". No personal bylines.
- **Honesty over marketing** — say what the plugin does NOT do as clearly as what it does.
- **No fabricated stats** — cite sources by name (Capacitor, Apple guidelines, etc.).
- **Code blocks** must compile / run as written. Use TypeScript over JavaScript.

## Social card

`static/img/social-card.png` (1200 × 630) is every page's `og:image` (`themeConfig.image`); social scrapers do not render
SVG. Its master `static/img/social-card.svg` is the product site's card, text outlined to paths. Export, from `static/img/`:

```bash
npx -y sharp-cli@6.1.0 --density 72 -i social-card.svg -o social-card.png resize 1200 630 -- flatten "#202211"
```

## Contribution & status

All planned content batches are complete; the site is the **canonical documentation** for the plugin. `plugin-version.json`, `docs/ai-integration.md`, and `docs/changelog.md` are generated by `yarn sync:from-plugin` (maintainer-only; reads the private plugin repo) — don't edit them by hand.

`main` is protected: contributions go through fork + pull request with one approving review and a green `build` check — see [CONTRIBUTING.md](./CONTRIBUTING.md). If you spot an error or want to suggest a topic, open an issue.
